# Spider-Man × Digitivia — The Web Suit

A mobile-first ecommerce concept for a 500-unit Spider-Man suit drop. Each physical suit is paired with a numbered motion identity and a Digitivia-designed ownership signal.

## Live site

- GitHub Pages: <https://digitivia1-spec.github.io/spider-digitivia/>
- Vercel mirror: <https://spider-digitivia-production.vercel.app/>

## Development

```bash
npm ci
npm run dev
```

Use `npm run build` for a production build. Pushes to `main` automatically deploy to GitHub Pages through the workflow in `.github/workflows/deploy-pages.yml`.
